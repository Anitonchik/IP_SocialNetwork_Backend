# Социальная сеть — Backend

Серверная часть социальной сети. Реализована на **Java (Spring Boot)** и предоставляет REST API для клиентской части на React.

---

## 📖 О проекте

Клиент-серверное приложение с разделением на бэкенд (Spring Boot) и фронтенд (React). Реализована ролевая модель доступа с двумя ролями — **пользователь** и **администратор**.

### Возможности роли «Пользователь»

- управление собственными постами (создание, редактирование, удаление);
- просмотр постов других пользователей;
- управление подписками и просмотр списка подписчиков;
- личные сообщения: переписка с пользователями, управление чатами и сообщениями (создание, редактирование, удаление).

### Возможности роли «Администратор»

- все права пользователя;
- управление пользователями;
- управление постами всех пользователей.

---

## Технологический стек

- **Java 21** — язык разработки;
- **Spring Boot 3.5.5** — фреймворк для построения REST API;
- **Spring Web** — REST-контроллеры;
- **Spring Data JPA + Hibernate** — ORM для работы с базой данных;
- **Spring Security + JWT (jjwt)** — аутентификация и авторизация по ролям;
- **Liquibase** — управление схемой базы данных (миграции);
- **PostgreSQL** (prod) / **H2** (dev) — базы данных;
- **Springdoc OpenAPI (Swagger UI)** — документация API;
- **Thymeleaf** — серверный рендеринг (fallback-страницы);
- **Gradle** — система сборки.

## Запуск проекта

### Требования

- JDK 21
- Gradle (используется Gradle Wrapper `./gradlew`)
- PostgreSQL — для prod-профиля
- Запущенный фронтенд — репозиторий: [ссылка на фронтенд](https://github.com/Anitonchik/IP_SocialNetwork_Frontend)

### Профили Spring

Проект поддерживает несколько профилей Spring, которые задаются через Gradle-свойства:

| Свойство      | Профиль(и)            | Описание                                                                 |
|---------------|-----------------------|--------------------------------------------------------------------------|
| *(по умолчанию)* | `dev`              | H2 (in-memory), Liquibase-миграции, Thymeleaf                             |
| `-Pprod`      | `prod`                | PostgreSQL, Liquibase-миграции                                            |
| `-Pfront`     | `front` (+ `dev`/`prod`) | Отдаёт статику и API, собирает фронтенд через Node Gradle-плагин      |

### Запуск в режиме разработки (по умолчанию `dev`)

```bash
# Клонировать репозиторий
git clone https://github.com/Anitonchik/IP_SocialNetwork_Backend
cd IP_SocialNetwork_Backend

# Запустить (по умолчанию bootRun + профиль dev)
./gradlew bootRun
```

Приложение запустится на `http://localhost:8080` (порт можно переопределить в `application.yml`).

### Запуск с профилем `prod` (PostgreSQL)

```bash
./gradlew bootRun -Pprod
```

Перед запуском убедитесь, что PostgreSQL запущен и параметры подключения указаны в `application-prod.yml`.

### Запуск с фронтендом (`-Pfront`)

```bash
./gradlew bootRun -Pfront
```

В этом режиме применяется `build.front.gradle` — Gradle-плагин Node собирает фронтенд, а бэкенд отдаёт собранные статику и API как единое приложение.

### Сборка JAR

```bash
./gradlew bootJar
```

Готовый JAR появится в `build/libs/` с именем `<project-name>-<version>.jar`.

### Запуск тестов

```bash
./gradlew test
```

### Swagger / OpenAPI

После запуска документация API доступна по адресу:

```
http://localhost:8080/swagger-ui.html
```

или

```
http://localhost:8080/swagger-ui/index.html
```
